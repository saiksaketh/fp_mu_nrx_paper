\section{Background}
\label{sec:qat_pruning}

This section reviews the MU-\gls{MIMO} uplink model, the convolutional
graph neural receiver that we compress, and the associated training
objective. It then recalls per-channel fake quantization and the
integer and floating-point microformats used as weight grids.
Activation quantization and magnitude pruning, which form the proposed
compression stack, are specified in Section~\ref{sec:nrx_qat}.

\subsection{Uplink Setup}
\label{sec:system_model}
$U$ single-layer \glspl{UE} share the same time--frequency resources
toward a base station with $B$ antennas. After OFDM demodulation, each
resource element $(s,t)$ observes
\begin{equation}
\label{eq:mu_mimo}
  \mathbf{y}_{s,t}
  = \sum_{u=1}^{U}
    \mathbf{H}_{s,t,u}\,\mathbf{x}_{s,t,u}
    + \mathbf{n}_{s,t},
  \qquad
  \mathbf{n}_{s,t}\sim\mathcal{CN}(\mathbf{0},N_0\mathbf{I}),
\end{equation}
with $\mathbf{y}_{s,t}\in\mathbb{C}^{B}$. Payload bits are
\gls{LDPC}-encoded and mapped to \gls{QAM} symbols; known
\gls{DMRS} tones enable an initial least-squares channel estimate.
The neural receiver consumes the full post-\gls{FFT} slot (data and
pilots) and emits per-bit \glspl{LLR} for a conventional 5G~NR
decoder.

\subsection{Neural Receiver Architecture}
\label{sec:architecture}
We build on the convolutional graph neural network (CGNN) of
\cite{scamnrx}, designed for flexible MU-\gls{MIMO} \gls{PUSCH}
reception; related deployment studies emphasize tight memory and
compute budgets \cite{wiesmayr2024design}. A small input CNN embeds
each resource element into a state of dimension $d_s{=}56$;
$N_{\mathrm{it}}{=}8$ unrolled blocks then mix information across
users (dense aggregation) and across the time--frequency grid
(separable convolutions); a final dense readout produces \glspl{LLR}.
Separable layers factor into a depthwise spatial filter and a
pointwise mixer; only the latter, together with the aggregation and
dense kernels, is eligible for pruning (Section~\ref{sec:pruning}).
The same weights apply across user counts and bandwidths, so a model
trained on $4$ \glspl{PRB} can be evaluated on a $132$-\gls{PRB} grid.
In the large configuration used here, both the input and state CNNs
have widths $[128,128]$, aggregation uses width $64$, and the readout
uses width $128$.

\subsection{Loss and Training Schedule}
\label{sec:loss}
Training is driven by bit-metric decoding quality with an auxiliary
channel estimate. If $B$ denotes the coded bits on data tones,
$\hat{L}$ the predicted \glspl{LLR}, and $\hat{\mathbf{h}}$ a
refined channel from a second readout, we minimize
\begin{align}
\label{eq:bce}
  \mathcal{L}_{\mathrm{BCE}}
  &= -\mathbb{E}\!\left[
       B\log\sigma(\hat{L})
       +(1-B)\log\!\bigl(1-\sigma(\hat{L})\bigr)
     \right], \\
\label{eq:mse}
  \mathcal{L}_{\mathrm{MSE}}
  &= \mathbb{E}\!\bigl[
       \|\hat{\mathbf{h}}-\mathbf{h}\|_{2}^{2}
     \bigr], \\
\label{eq:total_loss}
  \mathcal{L}
  &= \mathcal{L}_{\mathrm{BCE}}
     + \lambda\,\mathcal{L}_{\mathrm{MSE}},
\end{align}
with $\sigma$ the sigmoid. Both terms are summed over all
$N_{\mathrm{it}}$ unrolled receiver iterations, and $\lambda$ decays
from $0.02$ to $0.01$ across two schedule phases. Each optimizer step
draws a mini-batch of $N_B{=}128$ independently simulated OFDM
slots in Sionna \cite{sionna}, with random active-user counts,
velocities in $[0,56]$\,m/s, and rate-adjusted $E_b/N_0$ in a
phase-dependent window of approximately $0$--$15$\,dB. The
\texttt{FP32} baseline is trained with Adam; quantized models
warm-start from that checkpoint.

\subsection{Weight Fake Quantization}
\label{sec:fake_quant}
\gls{QAT} inserts a fake-quantization operator in the forward pass so
that the network experiences the same rounding and clipping noise that
low-precision inference will induce, while gradients update a
full-precision master copy of the weights
\cite{quantization_whitepaper,wu2020integer,jacob2018quantization}.
Let $\mathbf{W}$ denote a kernel (convolutional or dense) and let
$\mathcal{G}\subset\mathbb{R}$ be a finite quantization grid with
maximum magnitude $g_{\max}=\max_{g\in\mathcal{G}}|g|$. We use
\emph{per-channel abs-max} scaling along the output-channel axis:
for each output channel $c$,
\begin{equation}
\label{eq:absmax_scale}
  s_c = \frac{\max_{i}\,|W_{i,c}|}{g_{\max}},
\end{equation}
and the fake-quantized weight is
\begin{equation}
\label{eq:fake_quant}
  \widehat{W}_{i,c}
  = s_c\cdot\mathrm{round}_{\mathcal{G}}\!\bigl(W_{i,c}/s_c\bigr),
\end{equation}
where $\mathrm{round}_{\mathcal{G}}(\cdot)$ maps to the nearest
element of $\mathcal{G}$. Scales $s_c$ are recomputed from the live
weights on every forward pass (no frozen calibration set). Biases
remain in \texttt{FP32}.

For integer \gls{QAT} with bit-width $b\in\{4,8\}$ we use a symmetric
narrow-range grid
\begin{equation}
\label{eq:int_grid}
  \mathcal{G}_{\mathrm{INT},b}
  = \bigl\{-(2^{b-1}-1),\ldots,2^{b-1}-1\bigr\},
\end{equation}
so $g_{\max}=2^{b-1}-1$ and \eqref{eq:fake_quant} reduces to uniform
symmetric quantization with $2^{b}-1$ reconstruction levels
\cite{krishnamoorthi2018quantizing,wu2020integer}.

Because rounding is non-differentiable, the backward pass employs the
\gls{STE} \cite{bengio2013estimating,understanding_STE}, which
approximates
\begin{equation}
\label{eq:ste}
  \frac{\partial\widehat{W}}{\partial W} \approx \mathbf{I}
\end{equation}
(for integer grids, gradients outside the abs-max clip range are
additionally zeroed). Weight updates are therefore applied to the
full-precision master $\mathbf{W}$, while every subsequent forward
pass re-quantizes through \eqref{eq:fake_quant}. The resulting
training objective is the task loss evaluated under simulated
quantization,
\begin{equation}
\label{eq:qat_objective}
  \min_{\mathbf{W}}\;
  \mathbb{E}_{(\mathbf{y},\mathbf{b})\sim\mathcal{D}}
  \Bigl[
    \mathcal{L}\bigl(\mathbf{b},\,
    f(\mathbf{y};\,\widehat{\mathbf{W}})\bigr)
  \Bigr],
\end{equation}
where $\mathbf{y}$ is the received post-\gls{FFT} slot, $\mathbf{b}$
are the coded bits, $f(\cdot;\widehat{\mathbf{W}})$ is the neural
receiver with fake-quantized kernels, and $\mathcal{D}$ is the
training distribution of Section~\ref{sec:loss}.

\subsection{Floating-Point Microformats: FP8 and FP4}
\label{sec:fp_micro}
Low-bit floating-point formats allocate a non-uniform grid that
preserves dynamic range near zero, which matches the typically
heavy-tailed histograms of trained convolutional kernels
\cite{micikevicius2022fp8,rouhani2023microscaling}. We consider two
element formats standardized in the Open Compute Project (OCP)
microscaling family \cite{ocp2023mx}.

\textbf{FP8~(E4M3).}
An E4M3 value comprises one sign bit, four exponent bits, and three
mantissa bits. Following the OCP specification
\cite{micikevicius2022fp8,ocp2023mx}, the finite grid
has maximum magnitude $g_{\max}=448$. Relative to INT8, E4M3 provides
a comparable bit budget with non-uniform spacing that better covers
large dynamic ranges.

\textbf{FP4~(E2M1).}
An E2M1 value comprises one sign bit, two exponent bits, and one
mantissa bit, yielding the fifteen finite levels
\begin{equation}
\label{eq:fp4_grid}
  \mathcal{G}_{\mathrm{E2M1}}
  = \{0,\pm0.5,\pm1,\pm1.5,\pm2,\pm3,\pm4,\pm6\},
\end{equation}
with $g_{\max}=6$. At identical nominal $8\times$ weight compression,
E2M1 is a coarser but non-uniform alternative to INT4; both formats
use the same abs-max scaling \eqref{eq:absmax_scale} and
STE \eqref{eq:ste} during \gls{QAT}.
